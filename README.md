## WordPress PMS — source of truth

The `wordpress/staycore-pms/` directory in this website repository is an **obsolete v0.4.1 development snapshot**, retained temporarily for history only. **Do not install or deploy it.**

The maintained StayCore PMS plugin and regression tests live at:
https://github.com/karanzing1992/staycore-pms

The live WordPress site was verified using StayCore v0.8.1 on 11 October 2026.
Install only a release from the dedicated StayCore repository after its CI, staging, and compatibility checks. Website publishing and PMS deployments are separate workflows.

The GitHub Pages workflow publishes only `index.html`, not repository source files or WordPress plugin code.
