## Shared stack governance
**Andaz Lifestyle Stay** is the internal project/workspace alias. The canonical guest-facing name remains **Andaz Vibe Stay - Arambol, Goa**. Andaz's brand and property operations remain governed by [ANDAZ — MASTER](https://docs.google.com/spreadsheets/d/1bFreuhRYBFUQUf-RQ8U8pHkfDB8LN-j8ncnpIAUYqeA/edit#gid=160102026), now with a dedicated **Shared Tech Stack** tab.

The shared engineering standard is [MOKSHA MASTER — Technology Stack Registry](https://docs.google.com/document/d/1-dSumLKkhmpzqGF2P-4x5_ZNUh9JamH3ApfXv4y4EeM/edit). **Moksha Wellness** remains a separate wellness partner; no shared financial, guest, booking, identity or legal data. The accommodation PMS is [StayCore PMS](https://github.com/karanzing1992/staycore-pms), not a directory to deploy with this public website.

Before upgrades, check the actual live deployment and current source versions, upstream stable/security releases, compatibility and rollback. Record material changes in the master stack registry and the Andaz master sheet. Do not auto-deploy CMS/PMS/payment or data schema changes.
